
📌 PROJECT NAME : Number Guessing Game in C
📌 LANGUAGE     : C
📌 LEVEL        : Beginner → Intermediate
📌 TYPE         : Console Based Game

--------------------------------------------------------
🎯 PROJECT DESCRIPTION
--------------------------------------------------------
This is a simple and interactive Number Guessing Game
written in C language. The program generates a random
number and the player has to guess the correct number
within minimum attempts.

The game provides hints like:
✔ Too High
✔ Too Low
✔ Correct Guess

--------------------------------------------------------
🧠 CONCEPTS USED
--------------------------------------------------------
• Random Number Generation (rand, srand)
• Loops (while / do-while)
• Conditional Statements (if-else)
• Standard Input / Output
• Time-based Seed (time.h)

--------------------------------------------------------
⚙️ HOW THE GAME WORKS
--------------------------------------------------------
1️⃣ Program generates a random number.
2️⃣ User enters a guess.
3️⃣ Program compares the guess with the number.
4️⃣ Hints are displayed:
   - Guess too high
   - Guess too low
5️⃣ Game continues until the correct number is guessed.
6️⃣ Total attempts are displayed at the end.
